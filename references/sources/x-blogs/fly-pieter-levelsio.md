# fly.pieter.com (Pieter Levels, @levelsio) — one-line seed prompt, then many conversational turns (baseline for "vague prompt + human iteration")

- **Source URL:** https://x.com/levelsio/status/1893350391158292550 (2025-02-22, 1.59M views); completion post https://x.com/levelsio/status/1893385114496766155 (1.10M views, 4.3k likes)
- **Model/tool:** Cursor (the model isn't named in the post; Feb 22, 2025 predates Claude 3.7 Sonnet's release, so it was likely Claude 3.5 Sonnet in Cursor; later coverage says he also used Grok 3)
- **Genre:** Browser 3D flight sim, later multiplayer dogfighting (vanilla HTML/JS, "the whole flight sim is one HTML file")
- **Result evidence:** Live at http://fly.pieter.com ; widely covered (Decrypt, Indie Hackers). Commercially it reportedly reached ~$1M ARR within 17 days from in-game ads/sales, then declined (see https://promptway.com/blog/pieter-levels-flight-sim-to-zero).
- **Quality signal:** Huge reach (Elon Musk RT, "AI gaming will be massive"). Author's honest process note: "It didn't go 100% smooth ofc, but 80% yes, a few times I had to go back to previous versions and keep asking the same thing a few times to fix a problem."
- **One-shot vs iterative:** Heavily iterative: the seed prompt, then "many questions and comments from me". First version in 30 minutes, "done" in about 3 hours, then weeks of live iteration. The one-line prompt had almost nothing to do with the final product; the human's continuous playtesting did the design.

## Verbatim seed prompt

```
make a 3d flying game in browser with skyscrapers
```

(An example of his follow-up style, from the quoted ATC project in the same thread: "AMAZING WORK!! right now the border of the radar view is the same as arrivals board. i think we wanna try make it look like a real radar view waht u think? something like this image. we can use color filters?")

Use as a contrast case: a minimal spec works when the human is the design loop and playtests every turn. It is not evidence that a one-line prompt one-shots a game.
