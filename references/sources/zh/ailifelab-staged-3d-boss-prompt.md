# AI 生活實驗室：Claude + NVIDIA Trellis 半天做第一人称打 BOSS 3D 游戏（附四阶段 prompt）

- 来源 URL：https://ailifelab.co/blog/claude-nvidia-3d-game/ （2026-05-09，台湾作者，IG @life.coach.mtcity）
- 模型/工具：Claude（网页版 Artifacts 或 Claude Code 均可）；3D 模型由 NVIDIA Build 上的 Microsoft Trellis 文生 GLB；Three.js 单 HTML
- 游戏类型：第一人称 3D 动作打 BOSS（持剑，集气、大绝、子弹时间慢动作）
- 结果证据：仅作者文字描述（"集氣、大絕、子彈時間慢動作都有，聽起來像 demo 但真的能玩"），文中无可玩链接/视频链接（作者称在 IG 发过）→ 证据弱
- 热度：未知
- 生成方式：多轮迭代（先聊设计→资产清单→写码→"玩玩看→回報 bug→AI 修"）

## 作者的失败→修正（原文）

> 我自己最一開始犯的錯就是上來跟 AI 說「幫我做一個 3D 遊戲」。
> 這種 prompt AI 給你的就是一個方塊撞另一個方塊——沒靈魂、不好玩、也接不下去。
> 正確的順序是反過來——先把這四題聊清楚再叫 AI 動手：主角是誰、目標是什麼 / 敵人是誰 / 核心機制（攻擊？躲避？解謎？）/ 鏡頭視角（第一人稱？第三人稱？俯視？）

## Prompt 原文（作者给出的可复制模板）

```
我想跟你一起做一個能在瀏覽器跑的 3D 小遊戲。
設定：
- 我沒有遊戲開發經驗，你主導
- 用 Three.js 寫成單一 HTML 檔
- 角色 / 道具 / 環境的 3D 模型，我會去 NVIDIA Build 的 Microsoft
  Trellis（https://build.nvidia.com/microsoft/trellis）線上生成 GLB 下載
- 你先問我用的是網頁版 Claude 還是 Claude Code，再依照下面四階段進行
【階段 1：先把世界觀聊清楚】
- 問我想做什麼類型（打怪 / 解謎 / 跑酷 / 生存 / 派對）
- 一起決定主角是誰、目標是什麼
- 設計 3-5 個敵人或障礙
- 一個關卡場景（一個房間就夠）
- 核心遊戲機制（攻擊？躲避？收集？）
- 鏡頭視角（第一人稱 / 第三人稱 / 俯視）
這階段不寫任何程式碼，先聊清楚再進下一階段
【階段 2：資產清單】
列出我需要去 NVIDIA Trellis 生的所有 GLB。每個都給我：
- 建議檔名（譬如 hero.glb）
- 英文 prompt（直接貼給 Trellis）
- 用途（主角？敵人？裝飾？）
我會去生完下載到本機，告訴你檔名後再進下一階段。
【階段 3：寫程式】
- 一份完整的 index.html（Three.js 用 CDN 載入）
- 載入我下載的 GLB
- 實作我們討論的機制
- 基本 UI（HP 條、計分、開始/結束畫面、操作提示）
- 給我清楚的「怎麼跑起來」步驟（macOS / Windows 都要能跑）
【階段 4：除錯與迭代】
我會回報視覺、操作、bug 問題，你協助修正。規則：
- 一次改一個地方
- 提供修改的程式碼片段，不要每次重寫整個檔
- 解釋為什麼那樣改
請從問我用的是哪一種 Claude 開始。
```

## 备注

价值在 prompt 结构（分阶段、先设计后编码、范围收窄到"一個房間就夠"、迭代期"一次改一個地方"），而不在结果证据。作者自评："這個流程不會做出《薩爾達傳說》。但它會讓一個沒做過遊戲的人，半天交出一段「我自己在第一人稱打 BOSS」的影片"。
