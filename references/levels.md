# 怎么写关卡

有关卡、房间、谜题的品类（地牢冒险、解谜、平台、关卡制动作），GDD 里要有一节「关卡」，写到每一间房：玩家进门时会什么、看到什么、会先试错什么、靠哪个洞察解开。节奏曲线一节管的是房间之间怎么排，这一节管的是每间房里有没有题。范例是 `exemplars/juanbian-cards.md`。

## 一、为什么（一次实测）

卷边岛是一个 2D 塞尔达式小冒险：一张地上世界、一座 13 房的地牢、一个 Boss。GDD 写地牢时，每间房只有节奏表里的一行：「秒数 / 出什么 / 哇点」。14 行里有 3 行哇点是「—」，等于 GDD 自己承认这几间没有题。执行会话照着这张表把房间摆出来，自动驾驶能通关，事件日志校验通过。老板一试玩，就发现了这些问题：

- **房间里没有题。** 房 3 的地图摆在明处，螨虫守着的补丁撕开底下什么都没有；房 4 只能隔着栅栏看蛀虫游，什么也做不了；房 13 是同一个「卷→展开」做三遍。
- **Boss 的核心打法没人教过。** 蛀王一阶段要把它所在的那条地毯卷起来，把它卷进卷筒。可地牢里蛀虫只在房 4（只能看）和房 5（撕补丁打）出现过，后半段八间房一只都没有。「卷地毯能把底下的东西卷进来」到了 Boss 房才第一次出现，一见面就是考试。
- **地牢是一条直线。** 门表写死了 1→2→…→13，地图和罗盘拿到了也没有用；钥匙几乎是拿了就用，有一把开的就是本房自己的门。

事后补的两轮检查都没抓到这些。一轮是开工 8 小时后追加进 GDD 的节奏条目（每个区域的四拍、强度曲线、每房新元素不超过 2 个、相邻房间动词组合不重复），对照下来几乎全是「达标」；另一轮是逐房拿房间数据对 GDD 原文，18 间房和两个 Boss 判成「对得上」。两轮比的都是「实现和 GDD 一不一致」，GDD 本身没写题，空房间就照样过关。节奏规则只管房间怎么排，排的东西里有没有题，它们管不着。同一批追加条目里的手感锚点（宽容机制、停帧、屏震、前摇，每项一个数字），执行会话几乎逐条做到了。写成具体数字和具体内容的东西会被做出来，只写了规则的东西会被应付过去。

后来按本章的写法补了一版逐房谜题卡，上面三个问题当场全都暴露出来了。

## 二、先排知识链

写任何一间房之前，先把玩家在这一段要学会的东西列成一张表。每条知识是一句玩家能说出口的话（「补丁有重量，压在踏板上能顶替人」「鼓包停下发抖就是要咬了」），后面写它在哪几间房出现：

| # | 知识 | 安全地看一次 | 第一次考 | 换情境再考 | Boss 怎么用 |
|---|---|---|---|---|---|

规矩只有几条：

- **每条知识都走「安全地看一次 → 考 → 换个情境再考」。** 「安全地看一次」是指玩家在不会受伤、不会卡关的地方，完整地看到这个东西怎么动、怎么反应：隔着栅栏看一只会咬人的虫发抖，在没有敌人的房间里第一次卷地毯。
- **没教过的不考。** 表里任何一格「第一次考」前面都要有「安全地看一次」。
- **Boss 的每一个打法都要能在表里倒查到出处。** Boss 是整段知识链的期末考试，它用到的每个动作、每个敌人行为，前面都至少考过一次。查不到的就补一间房。
- **核心动词的每种用法都占一行。** 「卷」有搬、骑、碾、卷住敌人四种用法，就是四行知识，各自要走完一遍。

这张表放进 GDD 的关卡一节开头，执行会话改房间时也照着它查。

## 三、地牢的形状

在排房间之前先画一张房间连接图，标出锁和钥匙。

- **至少要有一个环或一条岔路。** 一条直线的地牢里，地图、罗盘、小钥匙都没有意义：路只有一条，钥匙拿了就用。有了环，玩家碰到锁着的门，才会想「钥匙在别处」，才会去打开地图。
- **钥匙不在锁的同一间或隔壁拿到**，除非是有意为之（比如教「钥匙」这个概念的第一间房）。
- **「看得见、够不着」的地标**：在前半段让玩家看到一个现在去不了的地方（栅栏后的宝箱、海对岸的平台），拿到地牢道具后回来就能去。这是道具「打开世界」最直接的证明。
- **地牢道具大约在 45–50% 处**，拿到后的房间都围着它转（这条从拆解里来，按品类标杆调）。

图用 ASCII 画，写进 GDD。

## 四、逐房谜题卡

每间房一张卡，回答六件事：

| 项 | 写什么 |
|---|---|
| 进门已会 | 玩家走进这间房时已经掌握的知识，引用知识链的编号 |
| 一眼看到 | 进门第一眼看到的目标和障碍。最好是「看得到、够不着」：钥匙在栅栏后面，门就在对面 |
| 先试的错法 | 玩家最先会试的那个做法，以及它在房间里**怎样失败**。失败要让玩家亲眼看到（门在眼前落下、拍子「叮」一声被弹开），失败本身就是线索。房间要保证这个错法真的走不通 |
| 洞察 | 解开这间房要想通的那一句话。它应该能从「错法为什么失败」推出来 |
| 线索 | 房间里有什么在指向洞察：缝线颜色、唯一一块能撕的补丁、敌人的站位、一句 NPC 台词。只在没有可读线索时才用文字提示 |
| 教会 → 考 | 这间房让玩家学会了哪条知识、后面在哪间房考 |

房间有不同的类型，卡的写法跟着变。**谜题房**六项写满。**战斗房**考的是操作，「洞察」写成这场仗的打法（谁先打、怎么用地形），直接写明「这是战斗房」，不要硬凑一个啊哈。**放松房**（峰值之后、没有伤害）也要有一件可做的小事和一个笑点。**预告房**用来安全地看一次后面要考的东西，「一眼看到」写清楚玩家看到了什么行为。

用设计师的口吻写，不写成验收条款：「我希望玩家先踩一下踏板就往门口跑，门会在他眼前落下——踏板到门的距离要够远，这一跑一定来不及。」

写完卡以后，自己把每张卡读一遍，回答两个问题。第一，「先试的错法」在这间房里真的会失败吗？如果玩家用最先想到的办法就过了，这间房就没有题。第二，一个只读过前面那些卡的玩家，能不能从「线索」推到「洞察」？推不到，就补线索，或者在前面加一间预告房。

## 五、排房间：节奏规则

卡写完、知识链排通以后，再用这些规则检查房间的排列。它们只管排列，只能放在卡的后面用，代替不了卡。

- **区域四拍。** 每个区域（地上世界、地牢前半、地牢后半）定一个核心概念，按引入、发展、变化、收尾排四拍。引入没有风险；变化让这个概念换一种用法（「撕」从开路变成打架）；收尾把它推到最大。
- **每间房新元素不超过 2 个。** 第一次登场的敌人、机关、动词用法都算。
- **强度曲线。** 峰值（战斗房、中 Boss）之后接一间放松房；Boss 是唯一超过 2 分钟的峰。
- **相邻两间房的「主动词 + 对手 + 地形」组合不重复。**
- **节奏目标。** 写成「我希望」的口吻，并写清怎么量：最长一段没有新东西的时间（比如不超过 90 秒）、最长一段什么都没发生的时间（比如不超过 20 秒）、每个核心动词学会以后被用在几种不同的情境里。

规则之间会冲突，要在 GDD 里写明怎么取舍。卷边岛就撞过一次：「第一次出现不能直接考」要求毛球先在没有危险的地方露面，「放松房不出新敌人」又不让它出现在峰后的放松房里，执行会话拿不准，只好交给老板。写成「隔着栅栏、碰不到的预告不算放松房里的新敌人」，这个冲突就不会发生。

## 六、手感锚点

动作类的关卡要靠手感撑起来，而手感数字是执行会话最会照做的东西，所以要写全，每项一个数字：

- **宽容机制**，每条写数值和理由：门口角点修正（偏离门中线几像素内自动推正）、洞边宽容（身体中心进洞格才算掉下去）、动作输入缓冲（动作结束前几帧内的按键记住）、交互目标吸附、受击击退不推人进洞。
- **反馈清单**，每项单独可开关：命中停帧（普通 / 击杀 / Boss 分档，写上限）、白闪、击退距离和减速帧数、粒子数和时长、屏震（每种事件的像素和帧数，沿冲击方向、逐帧衰减）、挤压拉伸、受击反馈、拾取飞向 HUD。
- **攻击前摇**：前摇时长 ≥ 0.25 秒反应时间 + 玩家应对动作生效的时间 + 余量。每种敌人写一行：前摇多长、怎么看出来、玩家用什么应对。同一屏同时出手的敌人数要有上限。
- **镜头**：锁定还是跟随、切屏多久、什么事件才推镜头。

锚点从拆解里来，用名作校准，偏离的地方写出理由。

## 七、其他品类

- **纯解谜**（推箱、机关、Baba 式规则）：没有战斗房和放松房，「先试的错法」和「洞察」就是全部。前 5–10 道题要真的写出来（布局画 ASCII），每道题的洞察不能重复。
- **平台跳跃**：知识链里的每条知识是一种地形或动作组合（「弹簧在落下前一刻踩才弹得高」）。卡按屏或按段写，「一眼看到」写目标平台在哪。
- **关卡制射击 / 动作**：每一段写成战斗房的卡，敌人组合也要走「安全见一次 → 考 → 换个情境考」。

## 八、写进 GDD 的哪里

关卡一节放在节奏曲线之后，顺序是：知识链表 → 地牢（或关卡）连接图 → 逐房谜题卡 → 节奏规则和取舍。GDD 是执行会话唯一的输入，这一节会让 GDD 变长（13 间房的卡大约 5–8k 字符）。长度上限可以为它放宽，卡不能删短：写得薄的房间，执行会话就会摆出一间没有题的房间。
